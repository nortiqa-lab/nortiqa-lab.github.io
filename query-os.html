Query OS

Exploración de datos en lenguaje natural con acceso gobernado: solo fuentes permitidas, validación previa y registro de cada consulta.

Pedir acceso → Ver productos

Estado

Prototipo interno. No es público.

Query OS corre hoy como laboratorio: consultas en lenguaje natural sobre datasets que el operador habilitó de antemano.

No es un chat suelto contra la base. Cada pregunta pasa por permisos, validadores y un registro auditable. El prototipo no está abierto en internet a propósito.

Fuentes permitidas Validación previa Registro Control humano

Cómo opera

Preguntar no es ejecutar.

El valor no es el modelo. Es el recorte: qué se puede tocar, quién valida y qué queda escrito.

  1. 01

    Capa semántica

    La pregunta se interpreta contra un mapa de datos permitido, no contra el esquema crudo.

  2. 02

    Validadores

    Antes de correr, se chequea alcance, fuente y si la consulta pide de más.

  3. 03

    Ejecución controlada

    Solo corre si el operador del sistema habilitó ese dataset y ese tipo de pregunta.

  4. 04

    Auditoría

    Queda registro de quién preguntó, qué se interpretó y qué se devolvió.

Acceso
